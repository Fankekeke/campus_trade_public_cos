# 基于 SpringBoot + Vue 的校园二手商品交易平台

二手交易 · 校内商铺 · 订单流转 · 在线沟通 · 评价互动 · 库存管理 · 数据统计 · 三端协同

本项目是一套面向高校场景的轻量级 C2C+B2C 二手商品交易平台，采用前后端分离架构，覆盖**管理员、用户（学生/教职工）、商家（校内商铺/个人卖家）**三类角色。系统围绕"商品管理、订单管理、评价管理、在线沟通、我的收藏、商品类型、商铺管理、库存管理、出入库详情、消息回复、公告管理、数据统计"等核心业务设计，支持从用户浏览商品、收藏关注、在线沟通、下单支付、确认收货、评价晒单，到商家商品上架、库存管理、订单处理、出入库记录、数据看板，再到管理员全平台监管、用户管理、商品审核、评价管理、数据统计的全链路数字化运营，同时融入校内商铺特色功能，构建校园二手交易生态。

## 核心特性

- **C2C+B2C 混合模式**：支持个人用户发布闲置二手商品（C2C），也支持校内商铺认证商家发布商品（B2C），两种模式订单流程统一但数据隔离，满足不同交易场景。
- **完整交易闭环**：覆盖"浏览商品→收藏关注→在线沟通→下单支付→确认收货→评价晒单"全流程，订单状态机涵盖待支付、待发货、已发货、已完成、已取消、已退款等状态，状态流转全程留痕。
- **校内商铺体系**：认证商家可开设校内商铺，管理店铺信息、商品上架、订单处理、库存管理、出入库记录，支持商铺主页展示（店铺公告、在售商品、交易评价、信誉等级），打造校园认证商家生态。
- **在线即时沟通**：集成买家与卖家/商家的在线沟通功能，支持文字、图片消息，沟通记录可追溯，方便商品咨询、价格协商、交易细节沟通，提升交易撮合效率。
- **收藏与关注**：用户可收藏心仪商品或关注喜欢的商铺，收藏商品降价/下架时自动提醒，关注商铺上新时推送通知，增强用户粘性。
- **评价与信誉体系**：交易完成后买卖双方可互评，评价数据计入商铺/个人卖家信誉分，好评率可视化展示，差评自动触发管理员关注，形成"交易—评价—信誉"良性循环。
- **库存与出入库管理**：商家端支持商品库存管理，商品售出自动扣减库存，支持手动库存调整与出入库记录查询，出入库详情全程可追溯，防止超卖与库存混乱。
- **数据统计看板**：管理员与商家端提供多维度数据统计，包括交易额趋势、订单量统计、热门商品排行、用户活跃度、商铺信誉分布等，支持图表可视化展示。

## 功能模块概览

## 管理员端

管理员为平台核心运营角色，负责全平台监管与运维：

### 账号与基础

- **账户登录**：支持管理员账号密码登录，支持修改密码与安全设置，登录日志全程记录。
- **用户管理**：管理注册用户信息，包括昵称、头像、手机号、邮箱、账户状态，支持用户账号冻结/解冻、违规用户处理。
- **商家管理**：管理校内商铺商家账号，包括商铺名称、商家信息、认证状态、信誉分、账户状态，支持商家入驻审核、商铺冻结/解冻。

### 商品与分类

- **商品类型**：管理商品分类，包括分类名称、图标、排序、描述，支持多级分类（如数码电子、教材书籍、生活用品、服饰鞋包、体育用品等）。
- **商品管理**：管理全平台商品，包括商品名称、图片、分类、价格、描述、卖家信息、上架状态，支持商品审核（违规商品下架）、商品搜索与筛选。
- **商家商品**：查看各商铺发布的商品列表，支持按商铺、分类、状态筛选，监控商铺商品质量。

### 订单与交易

- **订单管理**：查看平台全部订单（含个人交易与商铺订单），包括订单号、买卖双方信息、商品明细、订单金额、订单状态，支持订单筛选、退款处理、纠纷仲裁。
- **商家订单**：查看各商铺的订单数据，支持按商铺、时间、状态筛选，监控商铺交易情况。
- **商家库存**：查看各商铺商品库存情况，支持库存预警监控，防止超卖。
- **出入库详情**：查看全平台商品出入库记录，包括商品、数量、变动类型（售出/手动调整/退货入库）、变动时间、操作人，全程可追溯。

### 内容与互动

- **公告管理**：发布与管理平台公告，包括公告标题、内容、类型（通知/活动/规则）、发布时间、置顶状态，支持公告编辑与删除，用户端首页展示最新公告。
- **评价管理**：查看全平台交易评价，包括评分、评价内容、关联订单，支持评价审核（隐藏违规评价）、差评标记与纠纷处理。
- **用户收藏**：查看用户收藏的商品与商铺数据，分析用户偏好与热门商品，支持收藏数据统计。
- **消息回复**：管理用户/商家提交的咨询与反馈消息，支持管理员回复与消息记录查询，处理用户投诉与建议。

### 数据统计

- **数据统计**：综合数据看板，展示核心平台指标（今日交易额/订单量/新增用户/活跃商铺），支持交易趋势分析、热门商品排行、用户活跃度分析、商铺信誉分布、品类交易占比等多维度图表展示，支持报表导出。

## 用户端（学生/教职工）

用户为平台的交易参与者，可买卖二手商品或开设校内商铺：

### 账号与个人

- **账户注册登录**：支持手机号+验证码注册登录、账号密码登录，支持找回密码，首次登录自动创建用户档案。
- **密码修改**：支持用户自主修改登录密码，保障账户安全。
- **个人信息**：查看与编辑个人基本信息，包括昵称、头像、手机号、邮箱、个人简介，支持实名认证（开设商铺时需认证）。

### 交易与订单

- **商品浏览**：浏览平台商品列表，支持按分类、价格、新旧程度、发布时间筛选，查看商品详情（图片、名称、分类、价格、新旧程度、描述、卖家信息、用户评价），支持搜索商品。
- **校内商铺**：浏览校内商铺列表，支持按商铺名称、信誉分、商品数量筛选，查看商铺主页（店铺信息、在售商品、交易评价、信誉等级），支持关注商铺。
- **我的商品**：管理个人发布的二手商品，包括发布新商品（上传图片、填写描述、设置价格与新旧程度）、编辑商品、下架商品、删除商品，查看商品被浏览/收藏数据。
- **订单管理**：查看本人作为买家的全部订单，包括订单号、商品明细、订单金额、订单状态（待付款/待发货/已发货/已完成/已取消），支持订单筛选、取消待付款订单、确认收货、申请退款。
- **卖出订单**：查看本人作为卖家的全部订单，包括订单号、买家信息、商品明细、订单金额、订单状态，支持订单筛选、发货操作、处理退款、查看交易记录。
- **商铺订单**：开设商铺的用户可查看商铺全部订单，支持订单处理、发货管理、退款处理，与普通卖出订单数据互通但独立展示。
- **在线支付**：对待付款订单进行在线支付，支持微信支付、支付宝支付等多种方式，支付成功后自动更新订单状态并通知卖家。

### 互动与收藏

- **我的收藏**：管理个人收藏的商品与商铺，支持取消收藏，收藏商品降价/下架时自动提醒，关注商铺上新时推送通知。
- **评价管理**：对已完成订单进行评价，包括商品评分、服务评分、评价内容，支持查看历史评价记录与被评价记录。
- **在线联系**：与卖家/商家进行实时在线沟通，可就商品详情、价格协商、交易细节等交流，消息记录可追溯，支持发送图片。

## 商家端（校内商铺）

商家为平台认证商家角色，专注店铺运营与库存管理：

### 账号与店铺

- **账户注册登录**：支持商家账号注册登录，注册时需提交商铺信息与认证材料，审核通过后开通商铺，支持修改密码与安全设置。
- **密码修改**：支持商家自主修改登录密码，保障账户安全。
- **商家信息**：管理商铺基本信息，包括商铺名称、Logo、公告简介、联系方式、经营品类、信誉分，支持营业状态切换（营业中/休息中）。

### 商品与库存

- **我的商品**：管理商铺商品，包括发布新商品（上传图片、填写描述、设置价格与库存、选择分类）、编辑商品、上下架商品、删除商品，支持批量操作与商品搜索。
- **商品库存**：管理商品库存，查看各商品当前库存数量，支持手动库存调整（补货/盘亏），库存不足时自动预警提醒补货。
- **出入库详情**：查看商铺商品出入库记录，包括商品、数量、变动类型（售出/手动调整/退货入库）、变动时间、操作人，全程可追溯，方便库存对账。

### 订单与数据

- **订单管理**：查看商铺全部订单，包括订单号、买家信息、商品明细、订单金额、订单状态（待付款/待发货/已发货/已完成/已取消/已退款），支持订单筛选、发货操作、处理退款、订单搜索。
- **数据统计**：商铺数据看板，展示核心经营指标（今日交易额/订单量/新增收藏/好评率），支持交易趋势分析、热销商品排行、买家分布分析等多维度图表展示，支持报表导出。
